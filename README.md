# FiringRange
Simple Firing range demo 

This demo has 2 guns that you can pick up and shoot/play around with + a simple inventory system

The controlls are:

Movement: W A S D

Camera: Mouse

Shooting: Left click

Reloading: R

Inventory: I + Mouse (for looking at the items)
